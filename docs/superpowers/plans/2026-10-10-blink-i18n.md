# Blink 中英文语言选项与中文界面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 Blink 加 App 内语言开关（跟随系统 / 简体中文 / English），并把全部英文界面译成中文。

**Architecture:** 用 Android 13+ 原生 `LocaleManager.setApplicationLocales()` 做 per-app locale；AGP `generateLocaleConfig` 自动生成 `locales_config.xml`。文案从 Kotlin 字面量抽进 `res/values/strings.xml`（英文默认）与 `res/values-zh-rCN/strings.xml`（中文），Kotlin 侧改用 `stringResource(...)` / `context.getString(...)`。

**Tech Stack:** Kotlin 2.1、Jetpack Compose M3、AGP 8.7.3、Gradle 8.9、minSdk 34 / compileSdk 35。

**Spec:** `docs/superpowers/specs/2026-10-10-blink-i18n-design.md`

## Global Constraints

- **不新增任何依赖**：不用 appcompat、不用第三方 i18n 库；只用 `android.app.LocaleManager`（API 33+，minSdk 34 满足）与 core-ktx 自带的 `LocaleListCompat`。
- **只抽用户可见文案**：Compose `Text`、`contentDescription`、通知标题/正文、设置项标题与说明、按钮、厂商指引。**`Log.d/Log.e` 一律不动、不翻译**。
- **`app_name` 保持 `Blink`**，`values-zh-rCN` 不覆盖它。
- 带变量的文案用位置占位符：`%1$d`、`%2$02d`、`%1$s`（Kotlin 侧 `stringResource(R.string.x, a, b)`）。
- 资源名 `snake_case`，按界面前缀：`settings_*`、`home_*`、`overlay_*`、`notif_*`、`oem_*`。
- 厂商指引的**设置菜单路径保留英文原词**、用 `>` 分隔，外层中文说明。
- **本仓库没有 JVM 测试框架**（无 `testImplementation`），不为 i18n 引入 Robolectric。每个任务的"测试"是**真机 ADB 断言**（下节）。不改动测试基础设施。
- 模拟器在本容器不可用（无 `/dev/kvm`）。所有设备验证走真机 Honor BKQ-AN10，`export HOME=/home/ops` + `PATH` 含 `platform-tools`，设备 `127.0.0.1:35557`。

## 设备验证工具（每个任务复用）

`/tmp/blink-i18n-check.sh` —— 一条命令完成「装 APK → 清数据 → 设语言 → dump UI → 断言文案」。所有任务引用它，不重复实现：

```bash
#!/bin/bash
# Usage: blink-i18n-check.sh <lang: system|zh|en> <expect: string> [expect2 ...]
set -e
export HOME=/home/ops
export PATH=/home/ops/toolchain/android-sdk/platform-tools:$PATH
D=127.0.0.1:35557
LANG_TAG="$1"; shift
# locale tag used by LocaleManager
case "$LANG_TAG" in
  zh) TAG="zh-CN" ;; en) TAG="en" ;; *) TAG="" ;;
esac
adb -s $D shell pm clear com.cflat.blink >/dev/null
adb -s $D shell cmd appops set com.cflat.blink SYSTEM_ALERT_WINDOW allow >/dev/null
adb -s $D shell cmd appops set com.cflat.blink SCHEDULE_EXACT_ALARM allow >/dev/null
adb -s $D shell pm grant com.cflat.blink android.permission.POST_NOTIFICATIONS >/dev/null 2>&1 || true
if [ -n "$TAG" ]; then
  adb -s $D shell cmd locale set-app-locales com.cflat.blink --locales "$TAG" >/dev/null 2>&1 || true
fi
adb -s $D shell monkey -p com.cflat.blink -c android.intent.category.LAUNCHER 1 >/dev/null 2>&1
sleep 5
adb -s $D shell uiautomator dump /sdcard/ui.xml >/dev/null 2>&1
DUMP=$(adb -s $D shell cat /sdcard/ui.xml 2>/dev/null)
fail=0
for s in "$@"; do
  if echo "$DUMP" | grep -q "text=\"$s\""; then echo "  OK   '$s'"; else echo "  MISS '$s'"; fail=1; fi
done
[ $fail -eq 0 ] && echo "RESULT: PASS ($LANG_TAG)" || echo "RESULT: FAIL ($LANG_TAG)"
```

**注意**：`cmd locale set-app-locales` 需要设备支持；若 Honor 拒绝，改用 UI 点击设置页的 Language 三选一。两者都要在 Task 1 验证一次，确定可用的那条路径。

## Review Focus

以下五类是本 spec 隐含、但没有被某个任务的测试直接覆盖、且最可能出问题的点。每一条都在其归属任务里补了断言：

1. **带占位符的文案**（如通知 `%1$02d:%2$02d remaining`、时长 `%1$d min`）：漏了占位符会在运行时抛 `IllegalFormatException` 或显示成字面 `%1$d`。→ Task 4/2 断言。
2. **系统语言回退**：`system` 档下，系统为不支持的语言（如日语）时应回退到英文默认，而非空白或崩溃。→ Task 1 断言。
3. **应用名不被翻译**：中文界面下桌面图标与通知里的名字仍是 `Blink`。→ Task 1 断言。
4. **厂商指引在未覆盖机型上返回 null**：非列出的机型（如 Google Pixel）不应显示该段、更不应崩溃。→ Task 6 断言。
5. **悬浮层文案**：它由 Service 内的 `ComposeView` 渲染，**没有 Activity**，`stringResource` 依赖的 LocalContext 来自 Service —— 需确认能取到正确 locale 的字符串。→ Task 4 断言。

```kotlin
private fun applyStoredLanguage() {
    val tag = when (PrefsManager.getAppLanguage(this)) {
        "zh" -> "zh-CN"
        "en" -> "en"
        else -> ""            // 跟随系统
    }
    val lm = getSystemService(LocaleManager::class.java) ?: return
    lm.applicationLocales =
        if (tag.isEmpty()) LocaleList.getEmptyLocaleList()
        else LocaleList.forLanguageTags(tag)
}
```

- [ ] **Step 2: 加 Language 三选一**

在 `SettingsScreen` 的 `System` 段卡片里（`Start on Boot` 之后）加一段，照搬 Overlay Theme 的 `SingleChoiceSegmentedButtonRow` 写法：
```kotlin
var appLanguage by remember { mutableStateOf(PrefsManager.getAppLanguage(context)) }
// 段标题 settings_language；说明 settings_language_desc
listOf("system" to R.string.settings_lang_system,
       "zh" to R.string.settings_lang_zh,
       "en" to R.string.settings_lang_en).forEachIndexed { index, (key, labelRes) ->
    SegmentedButton(
        shape = SegmentedButtonDefaults.itemShape(index, 3),
        onClick = {
            appLanguage = key
            PrefsManager.setAppLanguage(context, key)

                "zh" -> LocaleList.forLanguageTags("zh-CN")
                "en" -> LocaleList.forLanguageTags("en")
                else -> LocaleList.getEmptyLocaleList()
            }
        },
        selected = appLanguage == key,
        label = { Text(stringResource(labelRes), style = MaterialTheme.typography.labelMedium) }
    )
}
```
